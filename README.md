# Salatic — конвертер и редактор файлов

Быстрый и приватный веб‑сервис для преобразования документов, таблиц, презентаций, электронных книг и изображений, а также для их редактирования. Файлы обрабатываются **прямо в браузере** пользователя и никуда не загружаются; сайт и API обслуживаются **Cloudflare Workers**.

## Возможности

### Конвертер

| Из | В |
|---|---|
| **PDF** (в т. ч. защищённые паролем и сканы) | Word (DOCX), OpenDocument (ODT), RTF, EPUB, TXT, Markdown, HTML, PDF с распознанным текстом, PNG/JPG постранично |
| **Word DOCX, Word 97–2003 DOC, OpenDocument ODT, RTF** | PDF, DOCX, ODT, RTF, EPUB, TXT, Markdown, HTML; таблицы документа → XLSX/ODS/CSV |
| **PowerPoint PPTX** | PDF (слайд в слайд), DOCX, ODT, RTF, TXT, Markdown, HTML |
| **EPUB** | PDF, DOCX, ODT, RTF, TXT, Markdown, HTML |
| **Markdown / HTML / TXT** | PDF, DOCX, ODT, RTF, EPUB, HTML/Markdown/TXT; HTML → таблицы |
| **Excel XLSX, Excel 97–2003 XLS, OpenDocument ODS, CSV, TSV, JSON** | друг в друга, а также PDF, DOCX, HTML, Markdown |
| **JPG, PNG, WebP, GIF, BMP, SVG, ICO, AVIF, TIFF (многостраничный), HEIC/HEIF** | PNG, JPG, WebP, BMP, TIFF, ICO, AVIF (если браузер умеет), PDF; распознавание текста → DOCX/TXT |

- Пакетная обработка в пуле Web Worker'ов, «Скачать все» одним ZIP, объединение изображений в один PDF.
- Перетаскивание, выбор файлов, вставка из буфера (Ctrl+V); готовые сценарии «PDF → Word», «PowerPoint → PDF», «DOC → DOCX» и др.
- Параметры: размер страницы (как в документе / A4 / Letter), качество JPG/WebP, DPI, разделитель CSV, режим OCR.
- **Защищённые PDF**: файлы с ограничениями прав открываются сразу, для файлов с паролем появляется запрос пароля (RC4 40/128, AES‑128, AES‑256). Результат сохраняется без пароля — об этом выводится уведомление.

**PDF → Word** восстанавливает структуру, а не «картинку»: абзацы, заголовки, начертания и семейства шрифтов, размеры, списки (включая векторные маркеры), таблицы по рамкам (с объединёнными ячейками) и по выравниванию столбцов, изображения, колонтитулы убираются; **многоколоночные страницы** читаются колонка за колонкой (включая абзацы, перетекающие в соседнюю колонку). Страницы без текстового слоя **распознаются (OCR, русский + английский)**.

**Документ → PDF** — собственная типографская вёрстка: метрически совместимые шрифты (Arial/Times/Courier/Calibri → Liberation/Carlito), автоматическая подстановка шрифтов для любых письменностей (кириллица, греческий, CJK, эмодзи), межстрочные интервалы как в Word, колонтитулы с номерами страниц, сноски внизу страницы, таблицы с переносом по страницам, **разделы с колонками** (перетекание текста между колонками и страницами, балансировка перед непрерывным разделом, линии между колонками), векторные рисунки EMF/WMF/SVG (с отсечением и градиентами) и **диаграммы Office** — как векторы с выделяемым текстом.

**Диаграммы** Word и PowerPoint (гистограммы и линейчатые, графики, области, круговые и кольцевые, точечные, комбинированные со второй осью) рисуются по сохранённым в файле значениям в стиле Office: «круглые» шкалы осей, подписи данных, легенда, цвета темы, числовые форматы. При сохранении в DOCX диаграмма остаётся **настоящей диаграммой Word** (её можно редактировать), в RTF — векторным рисунком.

### Редакторы

- **Редактор PDF** — объединение PDF и изображений, перестановка, поворот, дублирование, удаление и извлечение страниц, разделение на файлы; **правка существующего текста страницы** (щелчок по строке → исправление; подбираются шрифт, размер, начертание и цвет; старая строка **удаляется из файла**, остальной текст не сдвигается); **«Скрыть данные»** — настоящее редактирование конфиденциальных сведений: текст (включая невидимый слой OCR), векторная графика, пиксели изображений (в т. ч. JPEG) и ссылки под прямоугольником удаляются из PDF безвозвратно, область закрашивается; добавление текста, «замазка» (тоже удаляет текст под собой), маркер, рисование, изображение/подпись; отмена.
- **Редактор изображений** — обрезка с пропорциями, поворот, отражение, изменение размера, яркость/контраст/насыщенность, фильтры, кисть, надписи, отмена/повтор, экспорт в PNG/JPG/WebP/AVIF/BMP/TIFF/ICO. Открывает и TIFF/HEIC.
- **Редактор документов** — открывает DOCX, DOC, ODT, RTF, EPUB, PPTX, PDF, Markdown, HTML, TXT, таблицы; шрифты и размеры, выделение цветом, сноски, колонтитулы с номерами страниц, списки, таблицы, изображения, ссылки, разделы с колонками; диаграммы сохраняются при правке; автосохранение черновика; сохранение в DOCX, PDF, ODT, RTF, HTML, Markdown, TXT.

## Архитектура и выбор технологий

**Язык — TypeScript** (строгий режим) во всех частях: браузер, Web Worker, Cloudflare Worker и тесты используют один и тот же код ядра.

- **Скорость определяется тем, где идёт работа.** Обработка в браузере исключает загрузку файла на сервер и скачивание результата. Тяжёлые операции выполняет нативный код браузера (кодеки, Canvas, WebCrypto) и WebAssembly (HarfBuzz для подмножеств шрифтов, Tesseract для OCR, libheif для HEIC), всё — в Web Worker'ах, интерфейс не блокируется.
- **Cloudflare Workers** запускают код в изолятах V8 без «холодного старта»; статика раздаётся из кэша CDN, не вызывая скрипт.
- Сервер выполняет только лёгкие преобразования (см. API): лимиты Workers (CPU‑время, память) не подходят для PDF‑вёрстки и OCR.

```
Браузер
 ├─ UI (vanilla TS, без фреймворка)   — стартовый скрипт ≈ 6 КБ gzip, страницы грузятся лениво
 ├─ Пул Web Worker'ов                  — документы, таблицы, PDF, расшифровка, TIFF/HEIC
 │   └─ ядро src/core                  — модули подгружаются только когда нужны
 ├─ OCR (tesseract.js, свои модели)    — сканы и фото → текст, PDF с текстовым слоем
 └─ Canvas                             — изображения, PDF → PNG/JPG, редакторы
Cloudflare Worker
 ├─ Static Assets (+ _headers: CSP, кэш immutable)
 └─ /api/* — health, formats, convert (текстовые, офисные и табличные форматы)
```

Ядро построено вокруг промежуточных моделей (`src/core/model.ts`, `src/core/slides.ts`): читатели превращают байты в `Doc` (поток блоков), `Workbook` (таблицы) или `Deck` (слайды), писатели — обратно. N входных × M выходных форматов не требуют N·M конвертеров.

| Модуль | Назначение |
|---|---|
| `readers/pdf.ts` | PDF → Doc: строки, абзацы, заголовки, списки, таблицы, изображения, колонки |
| `readers/docx.ts`, `writers/docx.ts` | OOXML: стили, темы, нумерация, таблицы, сноски, колонтитулы, изображения |
| `cfb.ts`, `readers/doc.ts`, `readers/xls.ts` | контейнер OLE2, Word 97–2003 (MS‑DOC), Excel 97–2003 (BIFF8) |
| `readers/odf.ts`, `writers/odf.ts` | OpenDocument ODT/ODS: цепочки стилей, списки, таблицы, сноски, мастер‑страницы |
| `readers/rtf.ts`, `writers/rtf.ts` | RTF: кодовые страницы, списки Word и WordPad, таблицы, поля, сноски, рисунки |
| `readers/pptx.ts`, `writers/slides-pdf.ts` | PowerPoint: тема, мастер/макеты/плейсхолдеры, фигуры, группы, таблицы, градиенты → PDF |
| `chart.ts`, `drawingml.ts` | диаграммы Office (c:chartSpace) → SVG; цвета и градиенты DrawingML |
| `svg-render.ts`, `writers/emf.ts` | SVG → векторный список команд (пути, текст, градиенты, отсечение); список → EMF для Word/RTF |
| `pdf-redact.ts` | интерпретатор потоков содержимого PDF: удаление глифов, графики, пикселей изображений в областях |
| `readers/epub.ts`, `writers/epub.ts` | EPUB 2/3 |
| `writers/pdf.ts`, `pdf-fonts.ts`, `hb-subset.ts` | вёрстка PDF, подстановка шрифтов, подмножества через HarfBuzz |
| `metafile.ts` | интерпретатор EMF/WMF → векторы для PDF, SVG для веб‑форматов |
| `pdf-decrypt.ts`, `crypto.ts` | Standard Security Handler PDF (MD5, RC4, AES; SHA‑2 через WebCrypto) |
| `image-decode.ts` | TIFF (UTIF) и HEIC (libheif/WASM) |
| `pdf-tools.ts`, `text-lines.ts` | сборка PDF редактора, строки текста страницы для правки |
| `src/app/` | интерфейс, пул воркеров, OCR, растровые операции, редакторы |
| `src/server/index.ts` | Cloudflare Worker и API |

## Запуск

Требуется Node.js ≥ 22.13.

```bash
npm install
npm run dev        # разработка: http://localhost:5173 (Vite)
npm run preview    # сборка + локальный Cloudflare Worker (wrangler dev): http://localhost:8787
```

## Развёртывание на Cloudflare Workers

```bash
npx wrangler login   # один раз
npm run deploy       # сборка и публикация
```

Настройки — в `wrangler.jsonc`: статика из `dist/`, SPA‑маршруты отдают `index.html`, Worker вызывается только для `/api/*`. Заголовки безопасности и кэширования — в `public/_headers`.

## API

Сервер конвертирует форматы без вёрстки: **DOCX, DOC, ODT, RTF, EPUB, PPTX (как текст), Markdown, HTML, TXT, CSV, TSV, JSON, XLSX, XLS, ODS** (до 10 МБ). PDF и изображения обрабатываются в браузере — API отвечает `422` с подсказкой.

```bash
curl https://<host>/api/health
curl https://<host>/api/formats            # форматы и доступные преобразования

# тело запроса — файл; формат источника определяется автоматически
curl -X POST --data-binary @report.doc "https://<host>/api/convert?to=docx&name=report.doc" -o report.docx

# или multipart/form-data с полем file
curl -X POST -F "file=@sales.xls" "https://<host>/api/convert?to=csv" -o sales.csv
```

Ответ — файл с `Content-Disposition` (кириллические имена поддерживаются); предупреждения — в заголовке `X-Warnings` (JSON, URL‑encoded). Ошибки — JSON `{ "error": "...", "code": "..." }` с кодами 400/405/413/415/422/500. CORS открыт.

## Тестирование

```bash
npm test           # модульные и интеграционные тесты ядра (Vitest)
npm run test:e2e   # E2E в Chromium против собранного сайта под wrangler dev
npm run check      # сборка + все тесты
```

- **Модульные/интеграционные тесты (Vitest)** — полная матрица преобразований и проверка результатов **независимыми программами**: LibreOffice открывает наши DOCX/ODT/RTF/ODS и сам создаёт входные DOC/XLS/ODT/RTF/PPTX/EMF/WMF; poppler (`pdftotext`, `pdftoppm`, `pdffonts`) читает и растеризует наши PDF; pypdf шифрует тестовые PDF (RC4/AES), Pillow создаёт TIFF с разными сжатиями, ffmpeg/x265 — настоящий HEIC; координаты текста слайдов сверяются с рендером LibreOffice; примитивы шифрования — с Node crypto. Плюс «враждебные» входы: zip‑бомбы, глубокая вложенность, повреждённые и обрезанные файлы, огромные таблицы.
- **E2E (Playwright, 23 сценария)** — API и заголовки безопасности; конвертер (DOCX/DOC/ODT/RTF/EPUB/PPTX/XLS, многостраничный TIFF, HEIC, PDF с паролем и его запросом, OCR, пакетная обработка); все три редактора, включая правку текста PDF (старая строка исчезает из текстового слоя) и скрытие данных с JPEG‑фото; мобильная вёрстка.
- Вёрстка сверяется с LibreOffice попиксельно и по координатам слов: колонки, градиенты слайдов (цвета в пределах 10/255), диаграммы, отсечение в EMF; удаление текста проверяется на PDF из нашей вёрстки, LibreOffice и Chromium — удалённые слова исчезают, остальные не сдвигаются ни на 0,05 pt.
- Тесты, которым нужны LibreOffice, poppler, python3 или ffmpeg, пропускаются, если программы нет. Для E2E на своей машине: `npx playwright install chromium`. `BASE_URL=https://<host> npm run test:e2e` — прогон против развёрнутого сайта.

## Ограничения

Честный список того, что пока не воспроизводится:

- **PDF → Word** остаётся восстановлением структуры по эвристикам: сложные таблицы без рамок и без выровненных столбцов, плавающие надписи и текст по контуру могут потребовать ручной правки.
- **Word → PDF**: плавающие (обтекаемые) рисунки ставятся в поток текста; колонки разной ширины выводятся равными; все разделы получают размер страницы последнего раздела; вместо фирменных шрифтов используются метрически совместимые свободные аналоги.
- **Диаграммы**: объёмные (3D) рисуются плоскими, лепестковые и биржевые — как графики, пузырьковые — как точечные; поверхностные не рисуются (предупреждение). Нужны сохранённые в файле значения — их пишут Word, PowerPoint и LibreOffice.
- **PowerPoint → PDF**: SmartArt — только если в файле есть его готовое изображение; прямоугольные и «по фигуре» градиенты рисуются радиальными, узорные заливки — средним цветом; анимации не переносятся.
- **SVG**: фильтры, маски и узоры не применяются; у текста с градиентной заливкой — средний цвет. **EMF/WMF**: растровые операции, кроме копирования, не применяются; файлы только с EMF+ (без GDI‑записей) не отображаются. В EMF для Word прозрачность смешивается с белым (у Word 2016+ есть исходный SVG).
- **Правка текста PDF**: страница не переверстывается — новый текст длиннее старого может наехать на соседний (редактор предупреждает). **Скрытие данных** не трогает метаданные документа, закладки и значения полей форм; вертикальный текст CJK и изображения в форматах JPEG 2000, JBIG2 и CCITT под областью только закрашиваются (выводится предупреждение).
- Не поддерживаются: старые презентации `.ppt`, PDF, зашифрованные сертификатом (не паролем), книги с DRM.
- Нужен современный браузер (актуальные Chrome/Edge/Firefox/Safari): module‑воркеры, OffscreenCanvas, WebAssembly, WebCrypto.
